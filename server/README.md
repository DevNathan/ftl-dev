# ftl-dev language server (monorepo)

Optional LSP process for contributors. **Not** published to npm.

End users install FreeMarker support for Vim via [ftl-dev.vim](https://github.com/DevNathan/ftl-dev.vim) (Pathogen / Vundle / vim-plug) — no Node required.

## Local build

```bash
cd server
npm install
npm run compile
npm start
```

See [docs/publishing-language-server.md](../docs/publishing-language-server.md).
