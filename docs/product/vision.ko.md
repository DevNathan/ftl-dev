# 제품 비전

> Canonical: [vision.md](vision.md) (English). This file is a Korean summary.

## 왜 만드는가

FreeMarker(`.ftl`)는 “HTML 템플릿 생성”으로만 여겨지곤 하지만, 실제로는 Java 스택 위의 **빠른 스크립트/애플리케이션 로직**으로도 쓰입니다. 그 작업에는 C·Java에 가까운 에디터 도구가 필요합니다.

기존 CodeOSS 계열 FreeMarker 익스텐션은 얇거나 미완·관리 부실인 경우가 많습니다. **ftl-dev**는 하이라이팅, 네비게이션, 완성, FTL형 에디터 동작으로 **일상 FTL 개발**을 편하게 만드는 것이 목적입니다.

## 비목표 (현재)

- FreeMarker 런타임 대체.
- 템플릿에 노출된 모든 Java 빈에 대한 완전 IDE (best-effort만).
- CodeOSS 이외 에디터 우선 출시 (LSP는 이후 재사용 여지).

## 핵심 기능

- **신택스 하이라이팅**: `hash.key`, 함수/메서드, Java에서 넘긴 객체의 `obj.method` 등.
- **Goto / 네비게이션**: 매크로·함수·변수 선언 이동; import 심볼·경로 클릭 시 대상 파일 열기.
- **자동완성**: 디렉티브, built-in, 스코프 심볼 등 문맥 기반.
- **태그/디렉티브 닫기**: HTML식 자동 닫기를 FTL 문법에 맞게.
- **들여쓰기**: 가독성 위한 자동 들여쓰기. `#if` / `#elseif` / `#else`는 HTML처럼 깊게 들여 쓰지 않음(형제 분기 정렬).

## 성공 기준 (방향)

- 비사소한 FTL 스크립트 작성·탐색이 “템플릿 색칠”이 아니라 주류 언어 익스텐션에 가깝게.
- Java 타입 정보가 없어도 핵심 FTL 기능은 동작.
- 지식·결정은 저장소 `docs/`에 유지.
